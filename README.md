# GitPoulpi Scoop bucket

[Scoop](https://scoop.sh) bucket for [GitPoulpi](https://github.com/Poulpi-Lab/GitPoulpi), a lightweight cross-platform terminal Git client.

```powershell
scoop bucket add gitpoulpi https://github.com/Poulpi-Lab/scoop-gitpoulpi
scoop install gitpoulpi
```

Update with `scoop update gitpoulpi`. The manifest in `bucket/` is written by the GitPoulpi release workflow; do not edit it by hand.
